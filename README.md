# homebrew-jacu

Homebrew tap for [JACU](https://github.com/jacu-dev/jacu-harness).

First install (adds this tap):

```sh
brew install jacu-dev/jacu/jacu
```

After the tap is present:

```sh
brew upgrade jacu
brew install jacu
```

The formula is generated by GoReleaser and published on the JACU GitHub
Release as `jacu.rb`. A scheduled workflow may open a pull request to
sync it; it never pushes `main`. `main` requires a pull request, owner
review, and a check that the formula matches the signed checksums.
